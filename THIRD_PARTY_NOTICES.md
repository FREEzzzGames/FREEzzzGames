## 3. Licensing policy for future games

For every game we later self-host or bundle, we will record:
1. exact upstream project;
2. exact license/SPDX identifier;
3. copyright holder;
4. source URL;
5. whether attribution is required;
6. whether modifications are permitted;
7. whether commercial redistribution is permitted;
8. all required NOTICE/CREDITS/license files.

We will not assume that "free to play" means "free to redistribute". License obligations
belong to each individual work, not to the website that hosts it. This per-file approach is
consistent with common open-source distribution practice. citeturn0search0turn0search2

## 4. Important distinction

A third-party link is not a relicensing of the third-party work. If FREEzzzGames later
downloads, mirrors, embeds, modifies, or self-hosts a game, that game must receive its own
license audit before distribution.

This file is a provenance/notice record, not a claim that FREEzzzGames owns any third-party
game, trademark, artwork, music, or other content.
